# CropFlow

> From Farm to Market, Simplified.

CropFlow is an agricultural supply-chain management platform designed to connect farmers, buyers, and transporters through a centralized digital workflow.

## Project Status

🚧 In Development

## Core Workflow

Farmer → Marketplace → Buyer → Order → Transporter → Delivery → Confirmation

## Technology Stack

### Backend

- Spring Boot

### Web Application

- TypeScript

### Admin Portal
- Angular
- TypeScript

### Database

### Infrastructure
